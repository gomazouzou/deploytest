# Polinegon Sound

ハッカソンで制作した、子ども向けの音楽ゲームWebアプリです。

キャンバスに自由に絵や図形を描くと、それに合わせて音が鳴ります。
お絵描きと音楽作りを組み合わせることで、子どもが楽しみながら音楽制作を体験できることを目指して制作しました。

画面右下付近にある再生ボタンを押すと、音の再生が始まり、キャンバス上に描画できるようになります。

## 公開URL

https://deploy-polinegon-sound.vercel.app/

## ローカルでの実行方法

リポジトリをcloneした後、以下のコマンドを実行してください。

```bash
npm install
npm start
```

起動後、http://localhost:3000 からアクセスできます。
